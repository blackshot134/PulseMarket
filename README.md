## ✨ Features

- 💱 **Real-time Currency Rates** — USD, EUR, GBP, AED, TRY and 30+ more fiat currencies
- 🪙 **Crypto Market** — Bitcoin, Ethereum, Tether, Tron and 50+ cryptocurrencies
- 📊 **Complete Market Data** — Daily high/low, opening price, daily volatility
- 📈 **Trend Indicator** — Visual up/down/flat arrows for market direction
- ⚡ **Smart Search** — Search by name in Persian or English
- 🎨 **Beautiful UI** — Modern interface with rich Markdown formatting
- 🚀 **High Performance** — Async HTTP requests powered by `aiohttp`
- 🌐 **Global Data** — Sourced from [tgju.org](https://www.tgju.org)
